### Mapping

Die Kürzel der Klasse müssen denen in der z.B: `03_KW...` entsprechen.
Wenn dort z.B. `KP24B.` steht, dann ist das Kürzel `KP24B.` (mit Punkt) und nicht `KP24B` (ohne Punkt).
